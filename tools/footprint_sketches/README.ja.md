# Footprint 計測スケッチ

> English: [README.md](README.md)

`tools/footprint_matrix.py` が使用する固定のプローブスケッチです。ユーザー向けの
example ではありません。小さく安定した状態を保ってください。プローブを変更すると、
すべてのライブラリバージョンに対する計測基準が変わります。

`Base` は USB Host 共通の起動コストを計測します。他のプローブは代表的な機能を1つずつ
参照し、Flash とスタティック RAM の増分を `Base` と比較できるようにします。未使用の
ライブラリコードはリンカが除去するため、各プローブは計測対象の機能 API を必ず呼び出す
必要があります。
